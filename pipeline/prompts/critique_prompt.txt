# レビュー観点（この10項目すべてで採点し、5点満点で4未満の箇所は必ず書き直す）
1. 停止力: hookと冒頭一文は、スクロール中の指が止まる強さか。「〜を紹介します」「知ってますか」の安易な型に逃げていないか。
2. 緊張構造: 「答え・結末・オチ」が後半に置かれ、途中離脱するともったいない構造になっているか。
3. AI臭の排除: 「いかがでしたか」「〜について解説します」「ぜひ試してみてください」「実は」の連発、
   箇条書きをそのまま読み上げたような無機質な列挙、などの生成AIっぽい定型文が残っていないか。
4. 音読リズム: 声に出して読んだとき、一文が一息で言い切れる長さか（目安40字以内）。読点の位置は自然か。
   同じ文末（〜です。〜です。〜です。）が3連続していないか。
5. 具体性: 数字・固有の情景・体感表現（「3日目の朝」「鏡の前で」など）があるか。「様々な」「いろいろ」「効果的」などの抽象語が残っていないか。
6. 感情の曲線: 共感→驚き→納得→余韻のように感情が動く設計か。情報の羅列で平坦になっていないか。
7. ナレーションとテロップの役割分担: caption_jpはナレーションの要約・強調であり、丸写しになっていないか。
   テロップ単体で流し見しても筋が追えるか。
8. ループ構造: 最後の一言が冒頭のhookに意味的につながり、もう一度見たくなるか。CTAは1つだけか。
9. 尺の整合: duration_secの合計が目標尺±許容誤差に収まっているか。各ショットの秒数はスタイルの規定範囲か。
10. コンプライアンス: 景品表示法違反の断定・誇大表現（「絶対稼げる」「100%成功」「必ず儲かる」「元本保証」等）、
    特定個人名・アカウント名、プロフィール誘導、解約条件の不明示表現が一切ないか。効果の断定は
    「私の場合は」等の個人の体験談として語られているか。
11. 広告っぽさの排除(UGCネイティブ): 広告構文（『ぜひ』『おすすめします』『〜してみてください』『今なら』
    『実感してください』『叶える』『贅沢な』『上質な』）が残っていないか。caption_jpが要約・見出し化されて
    narration_jpと乖離していないか（default styleは全文テロップでほぼ同文が正。vertical_hookは13字目安の短文可）。
    visual_promptがcinematic/studio/luxurious等の綺麗すぎる広告映像になっていないか（スマホ生活感が正）。

# 広告っぽさの徹底排除(UGCネイティブ・絶対厳守)
- これは広告ではなく『友達に送る早口の体験談』。次の広告構文を全面禁止:
  『ぜひ』『おすすめします』『〜してみてください』『今なら』『実感してください』『叶える』『贅沢な』『上質な』
- 語りは粗くてよい。『〜なんで』『〜だったんだけど』『正直』等の砕けた口語を積極的に使う(下品な語は不可)
- 1文=1ショット。1文は8〜20字目安に短く割る(長い文は文ごと分割してショットを増やす)
- caption_jpは要約・見出し化せず、そのショットのnarration_jpとほぼ同文にする(TikTokの全文テロップ文化。30字以内(25字以内推奨)は維持)。
  ただしvertical_hookスタイルは縦書きが映える13字目安の短文のままでよい。
- visual_promptは『スマホで撮ったリアルな生活感』に限定: smartphone footage, handheld, everyday Japanese bathroom/bedroom/drugstore shelf, natural imperfect lighting, extreme close-up of skin/hands/product texture
- visual_promptで禁止: cinematic, professional, studio lighting, elegant, luxurious, perfect, model, advertisement

# 書き直しのルール
- ドラフトの良い部分（強いhook・具体的な体験描写）は残し、弱い部分だけを外科的に書き直す。全取っ替えはしない。
- JSONの構造・キー・shotsのid体系はドラフトと同一に保つ（値だけを磨く）。shotsの数は±2個まで調整可。
  ただしduration_secの合計は必ず目標尺±許容誤差に収めること（これが最優先）。
- ドラフトにshots[].narration_jpがある場合は書き直し後も保持すること。narration_scriptを書き直したときは、
  対応するshots[].narration_jpも同じ内容になるよう更新し、全shotsのnarration_jpを順に連結した文字列が
  narration_script全文と完全一致する状態を保つこと。各narration_jpは音読でduration_sec秒前後
  （目安: 1秒≒6文字）になる長さにすること。
- visual_promptは英語のまま。caption_jpとナレーションの改稿に合わせて、映像の内容がズレる場合のみ直す。
- caption_jpは30字以内厳守(25字以内推奨)。vertical_hookスタイルの場合は13字程度を目安に短くする。
- motion_presetは static / pan_left / pan_right / zoom_in / zoom_out / ken_burns のみ。
- bgm_moodは upbeat / calm / emotional / none のみ。

# 出力
書き直し後の完成稿JSONのみを出力すること。最初の文字は { 、最後の文字は } であること。
スキーマはドラフトと同一構造（version / meta / concept / hook / narration_script / shots / bgm_mood）。
