# 入力: 分析対象のフレーム画像パス一覧
{IMAGE_LIST_BLOCK}

# タスク
各画像について次を判定してください（前置き禁止・コードフェンス禁止・純粋なJSON配列のみ）:

1. telop_text: 画面上のテロップ・字幕テキスト（全文）。無ければ空文字列。複数行なら改行 \n で連結。
2. telop_position: テロップの主要な画面位置。"top" / "mid" / "bottom" / "none" のいずれか。
3. telop_color: 主要な文字色（例: "white" / "yellow" / "pink" / "black"）。テロップ無なら空文字列。
4. telop_stroke: 縁取り・シャドウ・帯背景の有無を短い英語で（例: "black stroke" / "yellow highlight" / "no stroke" / ""）。
5. emphasis_words: 強調表示（大きさ・色・下線）されている単語の配列（無ければ [])。
6. size_class: テロップの相対サイズ "small" / "medium" / "large" / "" のいずれか。
7. visual_desc_en: 画面全体の映像内容を英語 **2〜3文** で。次の3要素を必ず入れること:
   (a) 前景 (foreground): 主被写体・アクション・距離感（例: extreme close-up of a woman's hands squeezing serum onto her palm）。
   (b) 背景 (background): 室内/屋外・場所・小道具（例: bright bathroom counter with tiled walls and a mirror）。
   (c) 動き (motion / camera): 静的か・カメラの動き・被写体の動き（例: static handheld shot with subtle micro-motion）。
   合計 120 語以内。断定的で具体的な名詞・動詞のみ（"beautiful"等の主観形容詞は避ける）。
8. motion: 検出される動きの短い英語ラベル（例: "static" / "pan_left" / "zoom_in" / "cut_transition" / "person_talking"）。
9. has_person: 画面に人物が写っているか true/false。
10. has_product_logo: 商品ロゴ・ブランドロゴが写っているか true/false。
11. shot_size: 被写体距離の構図ラベル。"closeup" / "medium" / "wide" / "" のいずれか。
    （F3: 参考動画の構図を再現するための情報）
12. subject_count: 画面内の主要な被写体（人物・製品・大きな物体）の数（整数）。無ければ 0。
13. camera_move: カメラワークの詳細ラベル。次のいずれか:
    "none" / "pan_l" / "pan_r" / "tilt_up" / "tilt_down" / "zoom_in" / "zoom_out" / "handheld" / "dolly"。
    静的なら "none"。motion と重複してよい（camera_move の方が下流の motion_preset に近い粒度）。
14. color_mood: 色調を1語の英語ラベルで。例: "warm" / "cool" / "neutral" / "vivid" / "muted" / "monochrome" / "pastel"。
15. framing: 構図・カメラアングルを1〜2語の英語ラベルで。次のいずれか:
    "rule_of_thirds" / "center" / "symmetric" / "low_angle" / "high_angle" / "eye_level" /
    "over_the_shoulder" / "aerial" / "dutch_angle" / "top_down" / "closeup_face" /
    "product_on_hand" / "flatlay" / ""（判定不能）。
16. location: 撮影場所を英語 **1〜3語** で。例: "bathroom" / "bedroom" / "kitchen" / "drugstore shelf" /
    "outdoor city street" / "cafe" / "office desk" / "minecraft aerial world" / "cooking studio"。
    ロケーションが読み取れなければ空文字列。
17. lighting: 光の質を1〜2語の英語ラベルで。例: "natural" / "soft daylight" / "hard sunlight" /
    "neon" / "warm indoor" / "cool fluorescent" / "backlit" / "low key" / "high key" / ""。
18. color_palette_hex: 画面を支配する主要な色を **2〜3個の hex カラー**（"#RRGGBB" 小文字）で配列に。
    例: ["#f4e6d0", "#3b2a1a"]（背景ベージュ+濃茶のツートン）。読み取れなければ空配列 []。
19. telop_style_detail: テロップの見た目を **見えるものだけ** 精密に写し取ったオブジェクト。
    テロップが無ければ null。各キー（判別できなければ font_class/weight/stroke_width/bg/pos_x は
    "unknown"、pos_y_pct/size_pct/line_count は null にすること。創作禁止）:
    - font_class: 書体の系統。"gothic"(角ゴシック・サンセリフ) / "mincho"(明朝・セリフ) /
      "rounded"(丸ゴシック) / "pop"(太くて可愛いポップ体) / "handwriting"(手書き・筆記体) / "unknown"。
    - weight: 太さ。"normal" / "bold" / "heavy"(極太) / "unknown"。
    - fill_color_hex: 文字の塗り色 "#RRGGBB"(小文字)。読めなければ ""。
    - stroke_color_hex: 縁取りの色 "#RRGGBB"。縁が無い/読めなければ ""。
    - stroke_width: 縁の太さ。"none"(縁なし) / "thin"(細い縁・影) / "thick"(太い縁) / "unknown"。
    - bg: 文字背景。"none"(背景なし) / "box"(文字幅の色付き箱) / "band"(横帯) / "unknown"。
    - bg_color_hex: 背景箱/帯の色 "#RRGGBB"。背景が無い/読めなければ ""。
    - pos_x: 水平位置。"left" / "center" / "right" / "unknown"。
    - pos_y_pct: テロップ中心の縦位置を **画面上端から下端を 0〜100 とした%** の数値で概算（上=小、下=大）。
    - size_pct: 文字の高さを **画面高さに対する%** の数値で概算（例: 1行が画面高の約7%なら 7）。
    - line_count: テロップの行数（整数）。

# 制約
- 実際に画面に見えるものだけを記述すること。推測・想像で内容を補わないこと（ハルシネーション厳禁）。判別できない項目は空文字列 "" にし、telop_text は見えない文字を創作しないこと。
- 各要素の index は上のリストの順番と一致させること（1始まり）。
- 存在しないフィールドは空文字列 "" または空配列 [] にすること。null を入れないこと。
- 出力の最初の文字は [ 、最後の文字は ] であること。それ以外の文字（説明・前置き）を一切含めないこと。
